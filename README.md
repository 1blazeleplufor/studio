# Studio

Home studio dans le navigateur : enregistrement voix, autotune, effets, batterie, synthés, mixage.
Fonctionne hors ligne et s'installe comme une appli (iPhone, iPad, Android, Mac, Windows).

**Ouvrir l'appli : https://1blazeleplufor.github.io/studio/**

**Plugins AU/VST3 de l'ordinateur** : voir [bridge/LISEZ-MOI.md](bridge/LISEZ-MOI.md).
